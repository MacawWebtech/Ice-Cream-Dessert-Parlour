Template guide.

Everything you need to customise the Cone & Co. HTML template.

1. Getting started

Extract the project folder and open index.html in a modern browser. For local development, use VS Code with Live Server or run a simple static server from the project root.

2. Pages included

Home, alternate home, Menu, Menu Details, About, Offers, Party Orders, Gallery, Contact, Blog, Blog Details, Pricing, Login, Register, 404, and Coming Soon.

3. Brand system

Primary Strawberry Pink: #E85D75. Dark Chocolate: #43251F. Vanilla Cream: #FFF3E2. Typography: Playfair Display for headings and Inter for interface/body text.

4. Edit business details

Change the WhatsApp number, brand label, phone and email in assets/js/config.js. Replace sample address, hours, testimonials, prices, and page copy directly in the HTML files.

5. Menu items

Menu product objects are stored in assets/js/menu-data.js. Update each product’s ID, category, name, descriptions, price, image, ingredients and allergen notes. Keep IDs unique and use one of the filter categories: scoops, shakes, sundaes, waffles, cakes, or specials.

6. Images

Current pages use remote Unsplash sample image URLs. Replace these with properly licensed image files before commercial distribution. Store local image files inside assets/images/ and update the corresponding URLs in the page HTML and product data.

7. Forms and integrations

Party and contact forms validate in the browser and display a sample confirmation state. They do not send email or store data. Connect a form endpoint, CRM, or email service. Login and registration are interface-only and require an authentication backend. WhatsApp links use the configurable phone number in config.js.

8. Theme and RTL

The theme controller in assets/js/theme.js persists the preference in localStorage and follows the system preference on first load. The RTL controller in assets/js/rtl.js mirrors layout positions; page copy is not translated and existing text alignment is preserved.

9. Customisation files

assets/css/style.css contains the brand system, components.css contains shared alignment and equal-height card mechanics, responsive.css contains device breakpoints, dark-mode.css contains theme overrides, rtl.css mirrors layout, and motion.css contains animation states. JavaScript behaviour is organised by feature in assets/js/, including dedicated theme.js, rtl.js, and motion.js controllers.

10. Before publishing

Replace sample data and remote photography, confirm image and font licensing, add real contact and social URLs, connect forms and authentication, test all links on your target hosting, and run accessibility/performance checks.
